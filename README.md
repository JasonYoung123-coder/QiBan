# 栖伴 · QiBan

**一个有自己的性格、记得生活小事、能开口说话的桌面 AI 伙伴。**

栖伴把对话、语音和 Live2D 角色放在同一个陪伴空间里。你可以认真聊一会儿，也可以把它切成透明桌宠，安静地留在桌面上。

## 功能特色

### 有自己的性格

预置「栖栖」与「言川」两位伙伴，对应女性和男性 Live2D 形象及配套人设。可以一键选择，再自定义伙伴的名字、对你的称呼、性格和相处方式。偏向温柔倾听、轻松朋友，还是安静相伴，由你决定。人设会保存，并在后续对话中生效。

### 记住你愿意留下的小事

将偏好、称呼或重要的小事保存为记忆，新的聊天也能使用。每条记忆都可以修改和删除，内容由你掌控。

### 住在桌面上的角色

- Live2D 人形角色，支持闲置动作、眨眼、视线变化和点击互动。
- 透明桌宠与完整聊天窗口一键切换。
- 拖动、置顶、最小化、托盘和鼠标穿透。
- 低动态模式，减少身体动作。
- 导入自己的 Live2D 角色文件夹。

### 中文和英文，都能聊

对话可自动跟随输入语言，也可以固定为中文或英文。回复逐步显示，随时可以停止；收到的文字保留在本地聊天记录中。

### 让陪伴有声音

- **Windows 本地朗读**：使用已安装的中英语音包，无需额外语音账号。
- **六种配音风格**：女声撒娇学妹、知性灿灿、Vivi；男声温柔小哥、少年梓辛、深夜播客。设置中手动选择，也支持自定义音色 ID。
- **兼容语音服务**：可接入其他 HTTP 语音合成服务。
- **音频驱动口型**：根据实际播放音频的声音包络控制角色开口。
- **录音输入与实时通话**：接入语音识别服务后可录音输入；配置 LiveKit 与语音进程后可使用实时通话。

## 快速开始

### 便携版：复制即可启动

使用完整的 `QiBan-Windows-x64` 文件夹，在 Windows 10 / 11 x64 上双击 **`启动桌面.cmd`**。程序自带运行环境和男女角色素材，无需安装 Node.js、Python 或开发工具。最外层只有两个项目：

```text
QiBan-Windows-x64/
├─ 启动桌面.cmd
└─ app/              程序、素材、说明及个人数据
```

日常只需双击启动脚本，迁移时把整个文件夹一起复制。

首次启动后打开「设置」：

1. 展开设置中的获取指引，默认推荐 **DeepSeek**，可一键填入地址和模型，再前往官方页面获取密钥；也支持 OpenAI、OpenAI Responses 和 Anthropic。
2. 填入服务地址、模型名称和 API Key；官方接口可点击「填入官方地址」。
3. 点击「测试聊天连接」，确认后「保存连接设置」。下一次聊天立即生效。
4. 如需指定声音，在同一页面选择火山引擎，填写语音 API Key。默认使用撒娇学妹，可从六种声音中选择。语音密钥和服务开通也有可点击的官方指引。

三种聊天接口分别保存配置，切换不会丢失；已保存密钥不会回显，留空保留，勾选清除才会删除。未配置模型时，可通过明确标识的示范模式体验界面、角色和记忆操作。

完全退出程序后复制整个文件夹，可以携带连接设置、人设和聊天记录到新电脑。详细说明见 [便携版与迁移](docs/PORTABLE.md)。云端服务仍需网络和有效账号；本地朗读使用电脑已安装的语音包。

### 从源码运行

开发环境需 Windows 10 / 11、Node.js 22.12+ 或 24 LTS、Git 和 uv。

```powershell
git clone https://github.com/JasonYoung123-coder/QiBan.git
cd QiBan
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup.ps1
```

安装完成后双击 `启动桌面.cmd`，在设置页填写连接即可。源码仓库不含大型运行文件，源码下载后需完成首次安装；制作完整便携包见 [打包说明](docs/PORTABLE.md)。

更多音频设置见 [语音接入说明](docs/VOICE.md)。

## 日常操作

| 想做什么 | 操作 |
|---|---|
| 改变性格或称呼 | 打开「人设」，修改后保存 |
| 保存、纠正或忘记一件事 | 打开「记忆」 |
| 开始新的聊天 | 点击聊天窗口右上角的加号 |
| 切成透明桌宠 | 点击顶部显示器图标 |
| 返回聊天窗口 | 点击桌宠上方「聊聊天」 |
| 开启鼠标穿透 | 使用托盘菜单 |
| 恢复桌宠操作 | 按 `Ctrl+Alt+Q` |
| 停止回复或朗读 | 点击「停止」 |

## 本地数据

便携版的人设、记忆和聊天记录保存在 `app/.data/companion.db`，连接配置及明文密钥保存在 `app/.data/connections.json`，本地身份保存在 `app/.data/desktop-session.json`。完全退出后备份整个 `app/.data` 文件夹（源码运行时为根目录 `.data`）。已配置的文件夹含个人密钥和记录，请只迁移到自己的设备。

接入云端模型或语音服务时，完成请求所需的文本或音频会发送至你配置的服务。

## 当前版本

当前为 Windows 本地原型，优先验证陪伴体验：

- 界面为中文，对话和语音内容支持中英文；具体声音能力取决于语音包或服务。
- 记忆采用手动管理，最多保存 20 条；修改记忆会更新后续对话上下文。
- 自定义角色导入仅在本次启动中有效，动作丰富程度取决于角色素材。
- 桌面朗读按整条回复合成后播放；浏览器系统朗读使用基础口型动画。
- 实时通话需要单独配置服务并联调；此版本不适合直接作为公网多用户服务部署。

## 常见问题

**为什么还是示范模式？**  打开「设置」检查聊天地址、模型和密钥，使用连接测试并保存。

**为什么没有声音？**  开启「回复朗读」，并检查系统语音包或语音服务配置。

**为什么录音或实时通话不可用？**  这些功能需要配置语音识别或实时通话服务，详见语音接入说明。

**角色没有加载？**  运行 `npm run assets` 准备角色素材，然后重新启动。

**窗口未能启动？**  检查 `app/.data/backend.log`（源码版为 `.data/backend.log`），确认本地端口 `18765` 可用。
