# 栖伴 · QiBan

**一个有自己的性格、记得生活小事、能开口说话的桌面 AI 伙伴。**

栖伴把对话、语音和 Live2D 角色放在同一个陪伴空间里。你可以认真聊一会儿，也可以把它切成透明桌宠，安静地留在桌面上。

## 功能特色

### 有自己的性格

自定义伙伴的名字、对你的称呼、性格和相处方式。偏向温柔倾听、轻松朋友，还是安静相伴，由你决定。人设会保存，并在后续对话中生效。

### 记住你愿意留下的小事

将偏好、称呼或重要的小事保存为记忆，新的聊天也能使用。每条记忆都可以修改和删除，内容由你掌控。

### 住在桌面上的角色

- Live2D 人形角色，支持闲置动作、眨眼、视线变化和点击互动。
- 透明桌宠与完整聊天窗口一键切换。
- 拖动、置顶、最小化、托盘和鼠标穿透。
- 低动态模式，减少身体动作。
- 导入自己的 Live2D 角色文件夹。

### 中文和英文，都能聊

对话可自动跟随输入语言，也可以固定为中文或英文。回复逐步显示，随时可以停止；收到的文字保留在本地聊天记录中。

### 让陪伴有声音

- **Windows 本地朗读**：使用已安装的中英语音包，无需额外语音账号。
- **火山引擎音色**：支持指定音色，默认配置 `zh_female_sajiaoxuemei_uranus_bigtts`。
- **兼容语音服务**：可接入其他 HTTP 语音合成服务。
- **音频驱动口型**：根据实际播放音频的声音包络控制角色开口。
- **录音输入与实时通话**：接入语音识别服务后可录音输入；配置 LiveKit 与语音进程后可使用实时通话。

## 快速开始

### 1. 准备环境

- Windows 10 / 11
- Node.js 22.12+ 或 24 LTS
- uv（用于准备 Python 3.12 / 3.13 和项目依赖）
- Git

```powershell
git clone https://github.com/JasonYoung123-coder/QiBan.git
cd QiBan
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup.ps1
```

安装脚本会准备依赖、角色运行素材和界面，并创建 `.env`。已有 `.env` 会保留。首次安装需要联网。

### 2. 配置聊天模型

在 `.env` 中填写兼容聊天接口的服务地址、模型名称和密钥：

```dotenv
CHAT_BASE_URL=https://你的聊天服务/v1
CHAT_MODEL=你的模型名称
CHAT_API_KEY=你的密钥
```

服务需支持 `POST /chat/completions` 和流式回复。密钥仅由本地后端读取。

未配置模型时，可以使用明确标识的示范模式体验角色、界面和记忆操作；自由对话需要接入真实模型。

### 3. 启动栖伴

双击根目录的 **`启动桌面.cmd`**。

在「人设」中调整伙伴性格，输入第一句话即可开始。点击角色下方的「安静陪伴」可开启回复朗读。

### 4. 启用火山引擎音色（可选）

接口和音色已预填，只需设置：

```dotenv
TTS_PROVIDER=volcengine
VOLCENGINE_TTS_API_KEY=你的X-Api-Key
VOLCENGINE_TTS_RESOURCE_ID=seed-tts-2.0
VOLCENGINE_TTS_SPEAKER=zh_female_sajiaoxuemei_uranus_bigtts
```

完全退出并重启栖伴，开启「回复朗读」。语音密钥为空时继续使用系统声音；配置后，设置页会显示「火山引擎语音」。

更多音频配置见 [语音接入说明](docs/VOICE.md)。

## 日常操作

| 想做什么 | 操作 |
|---|---|
| 改变性格或称呼 | 打开「人设」，修改后保存 |
| 保存、纠正或忘记一件事 | 打开「记忆」 |
| 开始新的聊天 | 点击聊天窗口右上角的加号 |
| 切成透明桌宠 | 点击顶部显示器图标 |
| 返回聊天窗口 | 点击桌宠上方「聊聊天」 |
| 开启鼠标穿透 | 使用托盘菜单 |
| 恢复桌宠操作 | 按 `Ctrl+Alt+Q` |
| 停止回复或朗读 | 点击「停止」 |

## 本地数据

人设、记忆和聊天记录保存在 `.data/companion.db`；桌面会话信息保存在 `.data/desktop-profile`。备份前请退出程序，再一并备份这两处。密钥保存在 `.env`，不应提交到仓库。

接入云端模型或语音服务时，完成请求所需的文本或音频会发送至你配置的服务。

## 当前版本

当前为 Windows 本地原型，优先验证陪伴体验：

- 界面为中文，对话和语音内容支持中英文；具体声音能力取决于语音包或服务。
- 记忆采用手动管理，最多保存 20 条；修改记忆会更新后续对话上下文。
- 自定义角色导入仅在本次启动中有效，动作丰富程度取决于角色素材。
- 桌面朗读按整条回复合成后播放；浏览器系统朗读使用基础口型动画。
- 实时通话需要单独配置服务并联调；此版本不适合直接作为公网多用户服务部署。

```powershell

.venv\Scripts\python.exe -m uvicorn backend.api:create_app --factory --host 127.0.0.1 --port 18765

npm run dev
```

修改配置后重启本地服务；修改界面后运行 `npm run build` 再启动桌面程序。

| `src/` | 聊天界面、角色表现、播放与交互 |

## 常见问题

**为什么还是示范模式？**  检查 `.env` 的聊天地址、模型和密钥，保存后重启。

**为什么没有声音？**  开启「回复朗读」，并检查系统语音包或语音服务配置。

**为什么录音或实时通话不可用？**  这些功能需要配置语音识别或实时通话服务，详见语音接入说明。

**角色没有加载？**  运行 `npm run assets` 准备角色素材，然后重新启动。

**窗口未能启动？**  检查 `.data/backend.log`，确认本地端口 `18765` 可用。
