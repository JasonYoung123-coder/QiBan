# Windows 便携版

适用 Windows 10 / 11 x64。文件夹自带 Electron、Python 3.12、后端依赖、构建后的界面和本地角色素材。运行无需 Node.js、Python、Git、uv 或管理员安装。

## 使用与迁移

1. 将完整文件夹放到有写入权限的位置，例如 `D:\Apps\QiBan`；路径可以包含中文和空格。
2. 双击根目录的 `启动桌面.cmd`。
3. 打开「设置」，选择模型接口，输入服务地址、模型名称和 API Key。可先测试，再保存。火山引擎音色已预填，语音密钥也在这里填写。
4. 完全退出栖伴（含托盘），再复制整个文件夹到另一台 Windows x64 电脑。

首次收到的干净便携包不包含个人密钥或聊天记录。配置后，`.data/connections.json` 保存连接参数及明文密钥，`.data/companion.db` 保存聊天、人设、记忆，`.data/desktop-session.json` 保存对应的本地会话身份。请将这三项视作个人数据一起保管。复制给自己可以保留；分享给其他人应使用干净便携包。

桌面会话另外保存一份可迁移的本地凭据，避免 Windows 对 Chromium Cookie 的加密导致换电脑后找不到原来的记录。`.data/desktop-profile` 保留界面偏好。备份应在程序退出后进行，以保证数据库一致。

旧版 `.env` 仍作为初始配置来源。首次在设置页保存后，连接参数以 `.data/connections.json` 为准；界面清除密钥也不会被旧 `.env` 自动补回。高级 `DATABASE_URL` 如果自行指向外部数据库或绝对路径，则不属于默认便携配置。

## 运行边界

- 默认绑定 `127.0.0.1:18765`，同一台电脑同时运行一份；另一份占用时提示先退出，不混用数据。
- 未配置模型可体验本地示范。云端聊天、语音需要网络和对应账号权限。
- 本地中英朗读使用 Windows 已安装的语音包；指定火山音色需配置密钥。
- 实时通话需要可用的 LiveKit 房间服务和识别、合成服务。保存后可双击 `scripts/start-voice.cmd` 启动配套进程；修改实时连接参数后重启它。
- 完整目录必须一起复制，不要只拷贝启动文件。麦克风授权、系统声音和显卡驱动由新电脑提供。
- 当前验证采用同机改名、中文空格新路径及清空开发环境变量的迁移测试，不等于已在所有新电脑型号验证。

## 从源码制作便携包

先按 README 准备源码开发环境，再执行：

```powershell
npm run build
.venv\Scripts\python.exe scripts/build-portable.py
```

默认输出 `release/QiBan-Windows-x64`；目标已存在会停止，避免覆盖个人数据。可使用 `--output` 指定新的输出目录。构建环境需为 Windows x64 Python 3.12，并安装 voice 依赖。

打包脚本校验官方 Python 3.12.10 嵌入包 SHA-256，使用相对模块路径，排除开发环境 `.pth` 与缓存，不复制 `.env` 原件或 `.data`。`runtime-manifest.json` 记录依赖版本；各组件许可证随包保留。
